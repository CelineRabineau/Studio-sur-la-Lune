# Studio sur la Lune 

Site personnel de Céline Rabineau regroupant mes travaux, projets d’école et créations web personnelles.
https://celinerabineau.github.io/Studio-sur-la-Lune/

## À propos

Studio sur la Lune est un site portfolio / blog qui présente mes projets en design et développement web.

Il me permet de centraliser :
- mes projets scolaires
- mes expérimentations web
- mes travaux personnels
- un blog où je partage des projets moins important, certaines réflexions et découvertes et évolutions de projets
